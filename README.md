# Geometry Run

터치하거나 스페이스바를 눌러 장애물을 넘는 무한 달리기 게임입니다. 누르고 있으면 착지할 때 다시 점프합니다. 바닥의 띠는 해당 장애물을 피할 수 있는 점프 위치이며 가운데 점에 가까울수록 높은 점수를 얻습니다.

## 실행

Node.js 22에서 `npm install` 후 `npm run dev`를 실행합니다. 검증은 `npm test`와 `npm run build`로 실행합니다.

`src/rules.ts`의 속도, 점프, 장애물 간격, 판정과 점수는 실기기 플레이 전 **임시 밸런스**입니다. 충돌 크기나 물리 수치를 조정한 뒤에는 바닥 표시와 실제 충돌이 맞는지 다시 검증해야 합니다.

GitHub Pages 배포를 위해 저장소의 Pages 소스를 GitHub Actions로 설정해야 합니다. 기기별 터치, 화면 비율, 브라우저 동작은 실제 iPhone과 태블릿에서 확인해야 합니다.
